# English Vocab Battle｜英语词汇对战小游戏

像素中世纪魔幻风的**双队同屏英语对战游戏**，为教室大屏 / 希沃触控屏设计，也可以在普通电脑、平板上玩。

红队 vs 蓝队：看题答对就出兵，小兵在战场中线真刀真枪互相对抗，赢的一方继续攻城。把对方城堡血量打空，或者倒计时结束时血量更高，就赢了。

> 单文件、零依赖、免安装：整个游戏就是一个 `index.html`，双击就能玩，不用装环境、不用联网加载资源。

## 在线 / 本地运行

- **本地**：下载本仓库，双击 `index.html` 即可。
- **GitHub Pages**：仓库 `Settings → Pages → Source` 选择 `main` 分支根目录，保存后即可得到一个公开网址，教室里打开网址就能玩。
- **拷到 U 盘 / 发给同事**：只发 `index.html` 一个文件就够了。

## 玩法

1. 开始页选：对战模式（双人同屏 / 单人打电脑）、电脑难度、单局时长（90 秒 / 3 分钟 / 5 分钟）、题型。
2. 两队在各自答题区答题，互不干扰：
   - 双人：鼠标 / 触屏点选；也支持键盘——红队用 `1–8`，蓝队用 `Q–I`。
   - 单人：你打红队，电脑打蓝队，三档难度。
3. 答对出兵打仗，答错连击清零；结算页对比得分、答对数、正确率、最高连击、击破小兵数。

### 题型（5 种，可单选或混合）

| 题型 | 玩法 | 适合 |
|---|---|---|
| 拼写（单词） | 按音节块拼出单词，如「冒险」→ `ad` + `ven` + `ture` | 单词拼写巩固 |
| 中文找英文（释义） | 给中文，从选项里选英文 | 中小学生认词，推荐低年级用 |
| 英文找中文（释义） | 给英文，从选项里选中文 | 中小学生认词 |
| 短语 | 看中文点词块拼短语，如「告诫某人不要做某事」→ `warn sb. not to do sth.` | 初中核心短语 |
| 造句 | 看中文点词块拼完整句子 | 初中句子结构 |

释义题的干扰项是程序从词库里自动抽的其他词，不用手动写干扰项——加词条就能出题（见二次开发指南）。

题库规模（内置）：拼写 24、短语 17、造句 13、释义词库 40 组中英对照。

### 战斗与连击

- **小兵互相对抗**：步兵 / 骑士近战，法师远程；双方在中线相遇会停步对砍、掉血、同归于尽互相抵消，只有活下来的才能攻城。每队场上最多 14 个兵。
- **连击加成**：连击 2 起得分与伤害提升；**3 连**出骑士；**5 连**出法师；**8 连**狂热双倍出兵。
- **技能**：答对攒能量（满 6），可放火球术（直伤城堡 + 破兵）/ 治疗术。
- **冲锋号角**：每 45 秒触发一次，10 秒内双倍出兵。
- **排行榜**：开始页可填两队队名，每局结算自动记入战绩榜（胜场 / 总分 / 答对 / 最高连击）。
  注意：排行榜保存在**本次打开页面期间**（内存实现），关掉页面会清空；想做成永久榜，见二次开发指南里的改造路线。

## 项目结构

```
.
├── index.html          # 全部游戏：样式 + 题库 + 逻辑都在这一个文件里
├── README.md           # 本文件
└── docs/
    └── customize.md    # 二次开发 / 二创指南（改题库、调数值、换皮肤、加题型…）
```

单文件是有意为之：老师之间传文件、拷进教室电脑、离线使用都最方便。代价是文件较长（约 1500 行），改代码时善用编辑器搜索，按指南里给的「地图」定位即可。

## 二次开发 / 二创

详细的改法、参数表、二创点子都在 **[docs/customize.md](docs/customize.md)**，最常用的三件事先剧透：

1. **换 / 加题库**：在 `index.html` 里搜 `WORD_BANK`（拼写）、`MEANING_BANK`（释义）、`PHRASE_BANK`（短语）、`SENTENCE_BANK`（造句），照着现有格式加一行就是一道新题，适合把自己班课本的单元词表换进去。
2. **调难度 / 节奏**：城堡血量 `MAXHP`、兵种数值表 `UNIT`、连击门槛、电脑强度 `CPU_CONF`，都在指南里有对照表。
3. **换皮肤**：像素风样式集中在文件头部的 `<style>` 里，改配色、字体、城堡与小兵的 SVG 就能换成太空、海底、恐龙等任意主题——玩法不用动。

欢迎 fork 后做成你自己的版本：换学科（语文成语、数学口算、历史年代都可以套这个「答对出兵」的壳）、换语言（日语五十音、拼音）、换学段词表，做好了欢迎回链本仓库。
